# Portfolio-Website von Vadim Styr

## Projektbeschreibung
Diese responsive Website dient als mein persönliches Portfolio und präsentiert meine Projekte, Fähigkeiten und Kontaktinformationen. Die Seite wurde mit reinem HTML, CSS und JavaScript entwickelt, mit besonderem Fokus auf Barrierefreiheit und responsive Gestaltung.

## Funktionen
- Responsive Design für Mobile, Tablet und Desktop
- Barrierefreie Gestaltung (ARIA-Attribute, Skip-Links)
- Hamburger-Menü für mobile Ansicht
- Projektübersicht mit Detailbeschreibungen
- Kontaktformular und Social Media Integration
- Lebenslauf-Sektion

## Technologien
- HTML5
- CSS3 (Flexbox, Media Queries)
- Vanilla JavaScript
- FontAwesome Icons

## Projektstruktur
- `/index.html` - Startseite
- `/html/` - Unterseiten (Projekte, Kontakt, etc.)
- `/css/style.css` - Stylesheet
- `/js/` - JavaScript-Dateien
- `/img/` - Bildressourcen
